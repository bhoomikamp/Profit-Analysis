# Profit Analysis
### Datamites Certified Data Analyst Program

## Objective
Predict startup profit using Multiple Linear Regression based on 
R&D Spend, Administration, Marketing Spend, and State.

## Tools Used
- Microsoft Excel — Regression using Data Analysis ToolPak
- Orange — Visual regression + 10-Fold Cross Validation
- Power BI — Interactive dashboard with 4 visualizations

## Key Results
- R² Score: 0.9508 (model explains 95% of profit variance)
- Only significant predictor: R&D Spend (p = 2.58E-21)
- Predicted Profit Row 1: $70,190.39
- Predicted Profit Row 2: $70,711.71
